# 深图 · Agent 记忆层（MCP over stdio，只读）

**一句话**：让**本机的 agent**（Claude Desktop / Cursor / 任何支持 MCP 的客户端）能问"我上周看过的那个报价单在哪"，
拿回的是**带出处的锚点**——而不是把整个记忆库交出去。

设计依据：`文档/最新标准/Agent记忆层_设计与精度策略_2026-09-23.md` §四（作者已于计划 §15.12 第 3 条签字）。

---

## 一、四条边界（**它们决定合规故事还成不成立**）

| # | 边界 | 为什么 |
|---|---|---|
| 1 | **stdio，不开端口、不常驻** | agent **启动我们的子进程**、用 stdin/stdout 说 JSON-RPC。合规说明里那句「本机不存在任何能被别的程序 fetch 到记忆的端口」**继续成立**——**做成本地 HTTP 端口，整个合规故事当场报废** |
| 2 | **默认拒绝，按会话授权** | 没授权时除 `memory_scope`（本身不含任何记忆内容）以外**全部拒绝**，并把「怎么授权」原样告诉 agent。授权是一条命令、**限时**、可**立刻撤销** |
| 3 | **最小集** | 只给「**当前项目 + 最近 N 分钟**」，单次 ≤20 条；**私人库（`visibility=private`）永不出**（除非你在授权时**显式**加 `--include-private`） |
| 4 | **锚点化摘要，不倾倒原文** | 默认 `{id, 时间, 应用, 窗口标题, 文本片段, 原图路径, 可信度档}`；**OCR 全文只能靠 `memory_evidence` 单独索要**（顺带省 agent 的 token） |

**锚点长这样**（**真实字段名**，接客户端照这个写）：

```json
{
  "id": 1,
  "time": "2026-10-02 11:47:14",
  "app": "winword.exe",
  "title": "报价单-示例.docx",
  "text": "报价单 甲方：示例客户 乙方：我方 数量 3 台 单价 500 元 合计 1500 元",
  "file": "C:\\...\\深图\\screenshot\\演示_报价单.jpg",
  "conf": "高",
  "truncated": false
}
```

- `text` **最多 160 字**，被截断时 `truncated=true`；要全文就用 `id` 走 `memory_evidence`；
- `conf` 是**人话档位**（高/中/低，与界面同一套说法），不是小数；
- `file` 是那台机器上**原图**的路径——"能点回去核对"靠的就是它。

另外：**每次调用都写审计**（`mcp_audit.log`：时间 / 哪个 agent / 哪个工具 / 范围 / 给了几条，**含被拒绝的记录**）。

## 二、怎么用（三步）

> **只想先看看它到底能给什么**（15 分钟、**零隐私风险**）：先造一份**虚构的演示实例**——
> ```powershell
> venv\Scripts\python.exe 组件验证\Agent记忆层\造演示实例.py
> ```
> 它会造一份"示例客户/样例发票"的假实例（含一条私人库记录、一条别项目记录，用来演边界），
> 并把**注册片段、授权命令、问什么、什么算成功**直接打印出来。用完整份删掉即可，不碰你的真实例。

```powershell
# 1) 先看状态（默认是"关"）
venv\Scripts\python.exe mcp_memory_server.py --instance "<你的深图目录>" --status

# 2) 授权 30 分钟（你自己动手，这是"按次授权"的那一次）
venv\Scripts\python.exe mcp_memory_server.py --instance "<你的深图目录>" --grant 30

# 3) 用完立刻断掉；想回看谁问过什么：
venv\Scripts\python.exe mcp_memory_server.py --instance "<你的深图目录>" --revoke
venv\Scripts\python.exe mcp_memory_server.py --instance "<你的深图目录>" --audit 20
```

**在任何支持 MCP 的客户端里注册它**（以 Claude Desktop 的 `claude_desktop_config.json` 为例；
其它客户端只要支持 stdio server，字段名大同小异）：

```json
{
  "mcpServers": {
    "shentu-memory": {
      "command": "<仓库>\\venv\\Scripts\\python.exe",
      "args": ["<仓库>\\mcp_memory_server.py",
               "--instance", "D:\\深图自用"]
    }
  }
}
```

> 注册本身**不会**让 agent 读到任何东西——**还得你第 2 步授权**。
> 建议：**用完就 `--revoke`**，别长期挂着。

## 三、四个工具

| 工具 | 要不要授权 | 给什么 |
|---|---|---|
| `memory_scope` | **不要** | 授没授权、还剩几分钟、范围是什么。**不含任何记忆内容**（连项目名都不给） |
| `memory_recent` | 要 | 当前项目 + 最近 N 分钟的锚点化摘要 —— 参数 `{minutes, limit}`（默认 30 分钟、上限 20 条） |
| `memory_search` | 要 | 在当前项目里按关键词检索，返回同样的摘要 —— 参数 `{query, limit}`（`query` 必填） |
| `memory_evidence` | 要 | 某条锚点的**全文** + 原图路径 —— 参数 `{anchor_id}`（上面两个工具给的 `id`）；返回 `{"item": {…同款字段，text 不再截断…}}` |

## 四、自检（每次改动都跑）

```powershell
venv\Scripts\python.exe 组件验证\Agent记忆层\selftest_mcp_memory.py
```

它**真起子进程、真说 JSON-RPC**，在 `%TEMP%` 里造一个假实例（含**私人库记录**、别的项目记录、
超长文本），逐条断言：默认拒绝、授权后可读、**私人库永不出**、项目隔离、条数上限、文本截断、
全文要单独索要、审计含被拒记录、撤销后立刻拒绝、**源码里没有任何网络监听**。
判据 **0.0.56** 会跑它并断言退出码 0。

## 五、还没做的（别当成已有）

- **没进随包**：本版只在仓库里跑（`python mcp_memory_server.py`）。要随包发给试用者，
  得先做成独立 exe + 在设置里加一个可视化的授权开关（避免"命令行授权"挡住不写代码的人）。
- **没有可视化 UI**：授权/撤销/看审计目前都是命令。
- **不写记忆**：只读。agent 不能通过它往记忆里写东西（要写只能走深图自己的界面）。
